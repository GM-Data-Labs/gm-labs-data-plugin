# Jobs (GM Labs Data)

Tool: `appetizing_horsefly/ats-jobs-scraper` on the `gm-labs-data` MCP server. Billed per result to the user's Apify account.

## Examples
- "Use GM Labs Data to list all open engineering roles on Stripe's Greenhouse board."
- "Pull jobs from these Lever and Ashby boards and group by location: ..."

Tip: pass company board slugs/URLs; run defaults first to inspect fields.
